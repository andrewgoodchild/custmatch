# Examples

Every record in these folders is **synthetic**: generated by this project's scripts
(`research/scripts/make_demo.py`, `research/scripts/scenarios.py`, `research/scripts/au_customer_data.py`,
`research/scripts/customer_data.py`). The names come from public name-frequency lists, and the emails and
phone numbers are random. Any resemblance to a real person, address, email or number is a
coincidence; do not contact them.

| Folder | What it is |
| --- | --- |
| `demo/` | 1,766 records in three channels with 600 pairs already labelled - run it first |
| `scenarios/` | 24 hard cases with known answers (twins, Jr/Sr, spouses, reissued phones, ...), scored by `research/scripts/scenarios.py score` |
| `au/`, `synthetic/` | configs for the larger generated files; build those with the scripts in `docs/reproducing.md` |
